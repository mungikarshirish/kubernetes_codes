steps (follow document carefully, https://kubernetes.io/docs/home/)
  For upgrade CP  
    Changing The Kubernetes Package Repository
    Determine which version to upgrade to
    Upgrading control plane node
    Upgrade kubeadm:
    sudo kubeadm upgrade plan (verify current vs target)
    sudo kubeadm upgrade apply v1.36.x (verify version, it will upgrade etcd,api, controller and scheduler)
    Drain the node (cp)
    Upgrade kubelet and kubectl
    Uncordon the node (cp)
  For Upgrade worker nodes (follow doc carefully, https://kubernetes.io/docs/home/) need to upgrade one by one
    Changing The Kubernetes Package Repository
    Upgrade kubeadm
    Drain the node
    Upgrade kubelet and kubectl
    sudo systemctl daemon-reload
    sudo systemctl restart kubelet
    Uncordon the node (worker node)
